WorkBuddy 多用户 MCP

让最多约十名分析者同时调用同一套 EmulatRx HTTP MCP，每个人的队列和运行落在自己的目录里。省略用户头时行为与原来的单用户服务相同。

1. 用户是谁

已认证的 /mcp 和 /api/* 读取请求头 X-EmulatRx-User。只有这个头不存在时，才读取 X-WorkBuddy-User。两个头都给了，以 X-EmulatRx-User 为准。

合法名字是 1–63 个字符，匹配 ^[A-Za-z0-9][A-Za-z0-9._-]{0,62}$，并且不能是 .、.. 或带斜杠的路径。省略、空字符串会落到 default。不合法的值在进入工具之前返回 HTTP 400：

{
  "error": "INVALID_USER_NAMESPACE: ...",
  "code": "INVALID_USER_NAMESPACE",
  "error_code": "INVALID_USER_NAMESPACE"
}

本地 stdio 没有 HTTP 头，用启动参数或环境变量：

python -m emulatrx_tte mcp-serve --user-namespace dr_zhang
EMULATRX_DEFAULT_USER_NAMESPACE=dr_zhang python -m emulatrx_tte mcp-serve

2. 文件放在哪里

命名空间会话运行
default <runs>/sessions/<session_id> <runs>/<run_id>
其他用户，例如 dr_zhang <runs>/users/dr_zhang/sessions/<session_id> <runs>/users/dr_zhang/runs/<run_id>

users/<name>、sessions、runs 都以模式 0700 创建，并且解析符号链接之后必须仍在 runs 根目录里面。get_tte_run_status、get_tte_result_summary 和会话视图都带 user_namespace。甲的 session_id 或 run_id 对乙是 SESSION_NOT_FOUND / RUN_NOT_FOUND（HTTP 侧为 404）。每个用户最多保留 60 个会话和 100 次运行，不会清掉别人的目录。

3. 上传票据

ingest_cohort_session 设 issue_upload_ticket=true 时，票据里记下当时的 user_namespace。后面的上传地址不检查用户头，因为票据本身就是能力令牌：

curl -F "file=@cohort.xlsx" \
  http://127.0.0.1:8000/api/sessions/upload-ticket/<ticket_id>

文件写入 users/<票据里的用户>/sessions/<session_id>/raw/。.xlsx 与 .csv / .tsv 都可以。Excel 依赖 openpyxl==3.1.5（已列入 requirements-preview.txt）。

4. 并发

计算槽位数是 EMULATRX_MAX_CONCURRENT_RUNS，默认 8，允许 1–32。run_static_or_landmark_tte 和 run_grace_period_ccw 都会占用一个槽。槽位满了会等到 EMULATRX_SLOT_WAIT_SECONDS（默认 60，上限 300）。等到超时才返回 429 / BUSY。把等待设为 0 且槽位数设为 1 时，第二次计算会立刻 BUSY，便于测试。

EMULATRX_MAX_CONCURRENT_RUNS=8
EMULATRX_SLOT_WAIT_SECONDS=60

5. 从表格到三阶结果

  1. 用上面的用户头调用 ingest_cohort_session（直接给表，或先拿票据再上传 .xlsx）。
  2. diagnose_tte_feasibility 做可行性预检。
  3. run_static_or_landmark_tte，project_mode=user_cohort。
  4. get_tte_result_summary 在门禁通过时给出 tier_1_unadjusted_crude、tier_2_conventional_ps（含 psm_1to1 与 simple_iptw）、tier_3_target_trial_emulation 和 what_tte_controlled_beyond_psm。
  5. export_tte_artifact 读取 dualmode_report.html 或 audit_report.md。

HTTP MCP 仍使用 Authorization: Bearer <MCP_TOKEN>。用户头不能代替令牌。
