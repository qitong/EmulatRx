4. 显式 Fail-Closed 错误码与退出码契约边界

返回码 稳定错误标识（Error Code） 触发条件与 Fail-Closed 处置机制
CLI 0 / HTTP 200·202 passed / protocol_aligned 契约、四维 PICO-T 核验及统计门禁全部通过，完整发布估计结果与 SHA-256 审计清单。
CLI 退出码 2 MISSING_TIME_ZERO · POST_TIME_ZERO_ELIGIBILITY · POST_LANDMARK_COVARIATE_LEAK · NON_SYNTHETIC_COHORT_REJECTED · UNSUPPORTED_EVALUE_MEASURE · OUTPUT_EXISTS 协议结构缺失、时间零点/期后协变量时间穿越、合成模块混入非 SYN-* 主键、单事件 E-value 误用于 sHR 或输出目录已存在：立即中止且零残留。
CLI 退出码 3 POSITIVITY_VIOLATION · ESS_RATIO_BELOW_MIN · SMD_EXCEEDS_MAX · PRE_TRUNCATION_WEIGHT_EXCEEDED · EXCESSIVE_WEIGHT_TRUNCATION · POST_GRACE_SMD_EXCEEDS_MAX · UPSTREAM_GATE_NOT_PASSED 倾向/IPCW 正值性崩溃、有效样本量不足、加权后残余失衡或过度截尾掩盖极值权重：仅发布诊断与流失证据，100% 省略点估计文件（estimates.json / ccw_estimates.json）。
HTTP 401 / 403 authentication required 缺失凭证、密码或 Token 不匹配、用 Web Basic 访问 /mcp，或用 MCP Bearer 访问未开放 Bearer 的页面路由，以及非白名单 Host 请求。
HTTP 403 USER_NAMESPACE_MISMATCH 凭证绑定的命名空间与 X-EmulatRx-User 不一致。共享 MCP 令牌和共享 Web Basic 只能进入 default；lisi 的令牌不能读取 zhangsan 的目录。
HTTP 404 SESSION_NOT_FOUND · RUN_NOT_FOUND · ARTIFACT_NOT_FOUND 未知、过期或已执行一键物理擦除的会话、关联运行及产物下载请求。
HTTP 413 COHORT_FILE_TOO_LARGE Content-Length 或 64 KiB 流式分块累计超过 25 MB 上限时立即中断读取并释放内存缓冲。
HTTP 400 PRIVACY_VIOLATION_BLOCKED · ORIGIN_MISMATCH · INVALID_MAPPING · INVALID_USER_NAMESPACE 外发 LLM 请求体隐私守卫检出潜在个体标识/非白名单单元格值、跨站 Origin 不符或映射/协议参数非法。用户头 X-EmulatRx-User（缺省时 X-WorkBuddy-User）若含路径、空白、空字节或超过 63 字符，或重复/冲突，在进入路由前返回 400。头完全省略才使用令牌绑定的命名空间。
HTTP 422 ARM_MISMATCH_CONFIRMATION_REQUIRED 候选 RCT 双臂与研究干预/对照不一致（如 NCT06642272 恩格列净 vs 达格列净、缺联合背景药、单臂/无分组或 0/1 匿名分组未声明通用名，匹配度硬上限 ≤0.45/0.72）且未显式传入 confirm_arm_mismatch=true。
HTTP 422 PROTOCOL_MISMATCH_CONFIRMATION_REQUIRED 双臂药物虽匹配但四维 PICO-T 任一维度偏离——健康受试者/药代试验（如 NCT00842556 硬上限 ≤0.20）、缺失关键疾病合并症如心衰（上限 ≤0.55，严格排除 Exclusion Criteria 假阳性）、主要终点为血酮/HbA1c 等短期替代指标（如 NCT03959501 硬上限 ≤0.48）或随访期过短——且未显式传入 confirm_protocol_mismatch=true。

6. WorkBuddy 多用户 MCP

离线步骤说明见 docs/WORKBUDDY_MCP_SETUP.html。EMULATRX_MCP_USER_TOKENS_FILE（{"zhangsan": "<token>", "lisi": "<token>"}）把每位同事的 Bearer 绑定到 /data/tte/users/<user>/。可选 X-EmulatRx-User: zhangsan 必须与令牌一致；冒充他人返回 403 USER_NAMESPACE_MISMATCH。共享 Web Basic 不能进入命名用户目录。显式空头或纯空白头返回 400 INVALID_USER_NAMESPACE。头完全省略时使用令牌绑定的命名空间：共享 MCP_TOKEN 与 Web Basic 仍是 default，继续使用原来的 sessions/ 与运行根目录。命名用户写入 users/<user_namespace>/sessions 与 users/<user_namespace>/runs，模式 0700。别人的 session_id / run_id 得到 SESSION_NOT_FOUND 或 RUN_NOT_FOUND。

并发池由 EMULATRX_MAX_CONCURRENT_RUNS（默认 8，夹在 1–32）和 EMULATRX_SLOT_WAIT_SECONDS（默认 60）控制。run_static_or_landmark_tte 与 run_grace_period_ccw 在槽位耗尽并超过等待时间后才返回 429 BUSY。每个命名空间单独保留最多 60 个会话和 100 次运行。

队列文件支持 UTF-8/GB18030 CSV、TSV 以及 .xlsx（openpyxl==3.1.5）。上传票据记录签发时的 user_namespace，POST /api/sessions/upload-ticket/{ticket_id} 本身不需要用户头。stdio 用 python -m emulatrx_tte mcp-serve --user-namespace <slug> 或 EMULATRX_DEFAULT_USER_NAMESPACE。通过门禁的运行会在运行目录写入 dualmode_report.html，get_tte_result_summary 仍返回三阶梯队与 user_namespace。
