# Live public registration source receipt v1

`python -m emulatrx_demo metadata --nct-id "$NCT_ID" --out /path/to/new-directory` explicitly requests the current ClinicalTrials.gov API v2 `/api/v2/version` and `/api/v2/studies/{nctId}`. It accepts only `NCT` plus eight digits and uses only `https://clinicaltrials.gov`; redirects are rejected. Set `NCT_ID` to a public record of your choosing. This command requires network access and uses only the Python standard library.

The study request carries nested leaf `fields` for NCT ID, brief title, overall status, study type and design, conditions, arm and intervention names/types, primary outcome names/time frames, and the `hasResults` flag. The code applies the same whitelist again to the response in memory. It never writes study fields, raw JSON, contact details, eligibility text, descriptions, result numbers, patient records, or credentials. It never passes public metadata into the fixed template or seeded synthetic case generator.

Successful output is exactly `source/metadata.json` in a new output directory. Its [JSON Schema](../schemas/public-metadata-receipt-v1.schema.json) permits only the NCT ID, official record link, both actual request URLs, `retrievedAtUtc` (local UTC acquisition time), `apiVersion` and `dataTimestamp` as reported by the version endpoint, requested and actually projected leaf paths, the raw **study response bytes** SHA-256, the canonical projection SHA-256, and source attribution and nonclinical notice. Canonical projection bytes are UTF-8 JSON with sorted keys, compact `,` and `:` separators, and non-ASCII characters retained. The projection exists only in memory. Its hash can be recomputed only from an authorized fresh response with matching bytes and timestamp; the receipt alone cannot reconstruct the study values.

Attribution: [ClinicalTrials.gov](https://clinicaltrials.gov/) (U.S. National Library of Medicine). Its official record page is the link to use when displaying current information. Source format and handling were checked on **2026-11-22** against the [API v2 migration guide](https://clinicaltrials.gov/data-api/about-api/api-migration), [study data structure](https://clinicaltrials.gov/data-api/about-api/study-data-structure), [terms](https://clinicaltrials.gov/about-site/terms-conditions), and [linking guidance](https://clinicaltrials.gov/about-site/linking-to). `dataTimestamp` is kept in the API's exact format; the endpoint currently returns an ISO date-time without timezone, so the receipt does not claim it is UTC. `retrievedAtUtc` supplies the local processing date. Public registration metadata is not patient data or clinical efficacy evidence.

Invalid input, HTTP errors (including 404 and redirects), network failures, invalid/oversize JSON, missing required leaves, a mismatched NCT ID, and invalid version/timestamp fail with a named code and exit status 2. A failed request writes no output directory. An existing output directory is never overwritten. There is no cache or fallback to older snapshots. `demo` and `validate` remain offline and keep their separate `synthetic/` output contract.

The CI test replaces HTTP with fully synthetic responses. It never calls a live study endpoint and never ships a fixed real registration record.
